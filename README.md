# AI-Infused-2

In this repository, I am continuing my learning journey with Generative AI and gradually moving towards **RAG (Retrieval-Augmented Generation)**.

I have currently implemented two small projects:

## 1. Basic Chat Application

In this mini project, I experimented with building a basic chat application using **LangChain**.

* Built a simple chat application to interact with an LLM.
* Stored previous chat messages in a list to maintain basic conversation history.
* Reused my web-scraping project to scrape and summarize website content, but this time using **LangChain**.
* Learned the basics of working with LangChain for LLM-based applications.

## 2. Agent

In this mini project, I experimented with **LangChain Agents and tool calling**.

* Created a small agent that can answer questions about the prices of different items.
* Defined a dictionary containing prices for various items.
* Created a tool that allows the agent to retrieve prices from the dictionary.
* Learned how an agent can decide when to use a tool based on the user's question.

## Learning Goal

The goal of this repository is to build on the fundamentals from **AI-Infused** and gradually learn more advanced concepts such as **Agents, Tool Calling, RAG, and Retrieval**.
